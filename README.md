## Instalação
O botão **📲 Instalar App** fica visível no aplicativo.
- Android/Chrome: abre o prompt nativo quando disponível.
- iPhone/iPad: o botão orienta a usar Compartilhar > Adicionar à Tela de Início.

## GitHub Pages
Envie todos os arquivos do ZIP para a raiz do repositório e habilite Pages.


## Ajuste visual
Os pontos explicativos foram alterados para **ícones de lâmpada**, removendo as áreas coloridas sobre a imagem do conversor.


## Lâmpadas — padrão Área Fria
